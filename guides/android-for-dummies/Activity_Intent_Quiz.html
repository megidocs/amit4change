חלק 1

חזרה: בונים את מסך השאלה

  1. צרו פרויקט חדש עם שם משמעותי - למשל TrueFalseQuiz. השם באנגלית בלבד, בלי רווחים ובלי תווים מיוחדים. תבנית Empty Views Activity, שפה Java, ‏Minimum SDK ‏API 26, ‏Build configuration language ‏Groovy DSL.
  2. חובה, לפני שמוסיפים רכיב כלשהו: פתחו את activity_main.xml במצב Code, מחקו את כל התוכן שלו והדביקו במקומו את שלד ה-LinearLayout שמופיע מתחת לרשימה.
  3. בתוך השלד הוסיפו TextView עם id בשם tvQuestion: משפט על הנושא שלכם שאפשר לענות עליו "אמת" או "שקר", גודל טקסט 24sp, רוחב match_parent, והטקסט ממורכז.
  4. מתחתיו הוסיפו שורה אופקית (LinearLayout עם horizontal) ובתוכה שני כפתורים: btnTrue עם הטקסט "אמת" ו-btnFalse עם הטקסט "שקר". כל כפתור תופס חצי מרוחב השורה.
  5. לחיצה על כל כפתור מציגה Toast: "בחרת אמת" או "בחרת שקר".
  6. ב-colors.xml הוסיפו צבע בשם screen_bg והגדירו אותו כרקע המסך.
  7. הריצו ובדקו.

השלד זהה לזה של המדריך הקודם, עם שורה אחת חדשה: android:gravity="center" על הקופסה הראשית. היא ממרכזת את כל התוכן באמצע המסך.

בוחרים Empty Views Activity, לא Empty Activity

במסך בחירת התבנית יש שתי תבניות עם שם כמעט זהה, זו ליד זו. הנכונה היא Empty Views Activity, עם המילה Views.

איך מזהים שבחרתם לא נכון: במסך הבא אין שדה Language, ומתחת לכותרת כתוב "Jetpack Compose". במקרה כזה לחצו Previous, בחרו Empty Views Activity, ורק אז בחרו Java.

אל תמחקו את השורה android:id="@+id/main"

ב-MainActivity.java יש שורה ש-Android Studio כתב בשבילכם ומחפשת רכיב בשם main. בלי ה-id הזה האפליקציה לא תיבנה.

חלק 2

הסבר: Activity ו-Intent

כל האפליקציות שבניתם עד עכשיו היו מסך אחד. אפליקציות אמיתיות בנויות מהרבה מסכים: מסך כניסה, מסך ראשי, מסך הגדרות. היום האפליקציה שלכם מקבלת מסך שני.

Activity: מסך אחד

Activity הוא מסך אחד באפליקציה. כל Activity בנוי משני קבצים שעובדים יחד: קובץ XML שקובע איך המסך נראה, וקובץ Java שקובע מה המסך עושה. את הזוג הראשון אתם כבר מכירים: activity_main.xml ו-MainActivity.java. דימוי: חדר בבית. לכל חדר יש רהיטים משלו (ה-XML) וחוקים משלו (ה-Java).

Intent: בקשה לעבור מסך

מסך לא יכול "לקפוץ" למסך אחר בעצמו. הוא כותב בקשה ומוסר אותה למערכת אנדרואיד, והמערכת פותחת את המסך המבוקש. לבקשה הזו קוראים Intent. בבקשה כתובים שני דברים: מי מבקש, ולאן רוצים להגיע.

Extra: מידע שנוסע עם הבקשה

מסך התוצאה צריך לדעת אם צדקתם. המידע הזה נמצא במסך השאלה, ולכן צריך לשלוח אותו. מצמידים ל-Intent "פתק" שנקרא extra. לכל פתק יש שם (מפתח) ותוכן (ערך). המסך השולח כותב את הפתק עם putExtra, והמסך המקבל קורא אותו לפי אותו שם בדיוק.

ועוד קובץ אחד שכדאי להכיר: Manifest

AndroidManifest.xml הוא "תעודת הזהות" של האפליקציה. רשומים בו כל המסכים שלה. מסך שלא רשום שם לא יכול להיפתח, והאפליקציה תקרוס. כשיוצרים מסך בדרך שתלמדו מיד, Android Studio רושם אותו בשבילכם.

בונים צעד-צעד

אחרי כל תיבה כחולה של "הריצו ובדקו" מריצים ובודקים. לא ממשיכים הלאה עם שגיאה.

יוצרים מסך שני

4

עוברים למסך התוצאה עם Intent

פתחו את MainActivity.java. מצאו את הקוד של btnTrue מהחזרה. בתוך onClick, מחקו את שורת ה-Toast וכתבו במקומה את שתי השורות של ה-Intent. כך צריך להיראות הקוד של הכפתור:

MainActivity.java
Button btnTrue = findViewById(R.id.btnTrue);
btnTrue.setOnClickListener(new View.OnClickListener() {
    @Override
    public void onClick(View v) {
        Intent intent = new Intent(MainActivity.this, ResultActivity.class);
        startActivity(intent);
    }
});

אם Intent מסומן באדום: עמדו עליו, Alt+Enter, ‏Import class.

מה כתבנו פה

שורה ראשונה: כותבים את הבקשה. "אני, MainActivity, מבקש לפתוח את ResultActivity".

שורה שנייה: startActivity מוסר את הבקשה למערכת, והיא פותחת את המסך.

הריצו ובדקו

לחיצה על "אמת" פותחת את מסך התוצאה, עם הטקסט "כאן תופיע התוצאה". כפתור Back של המכשיר מחזיר לשאלה. הכפתור "חזרה לשאלה" עדיין לא עובד.

5

שולחים את התשובה עם putExtra

חלק ראשון: מסך השאלה צריך לדעת מהי התשובה הנכונה לשאלה שלכם. מיד אחרי השורה public class MainActivity extends AppCompatActivity { הוסיפו:

MainActivity.java (בראש המחלקה)
    boolean correctAnswer = false;

אם התשובה הנכונה לשאלה שלכם היא "אמת", כתבו true במקום false.

חלק שני: עדכנו את onClick של btnTrue. נוספו שלושה דברים: המשתנה userAnswer, בדיקת if שקובעת את isCorrect, ושורת putExtra.

MainActivity.java
btnTrue.setOnClickListener(new View.OnClickListener() {
    @Override
    public void onClick(View v) {
        boolean userAnswer = true;

        boolean isCorrect;
        if (userAnswer == correctAnswer) {
            isCorrect = true;
        } else {
            isCorrect = false;
        }

        Intent intent = new Intent(MainActivity.this, ResultActivity.class);
        intent.putExtra("isCorrect", isCorrect);
        startActivity(intent);
    }
});
מה כתבנו פה

userAnswer הוא מה שהמשתמש בחר. בכפתור "אמת" הוא true.

ה-if משווה את הבחירה לתשובה הנכונה. אם הן שוות, המשתמש צדק ו-isCorrect מקבל true. אחרת הוא מקבל false.

putExtra מצמיד ל-Intent פתק בשם "isCorrect", והערך שלו הוא מה שנמצא במשתנה isCorrect.

שני הכפתורים פותחים את מסך התוצאה. הטקסט עדיין "כאן תופיע התוצאה", כי המסך השני עוד לא קורא את הפתק.

7

קוראים את התשובה במסך התוצאה

צדקת!
חזרה לשאלה
התוצאה הרצויה בסוף הצעדתשובה נכונה מציגה "צדקת!", תשובה שגויה מציגה "טעית...". באיור הרקע ירוק רק להמחשה, את הצבע תוסיפו בהרחבה 1.

פתחו את ResultActivity.java. בתוך onCreate, אחרי השורות שכבר כתובות שם ולפני הסוגר } שסוגר את onCreate, הוסיפו:

ResultActivity.java (בסוף onCreate)
        TextView tvResult = findViewById(R.id.tvResult);

        boolean isCorrect = getIntent().getBooleanExtra("isCorrect", false);

        if (isCorrect) {
            tvResult.setText("צדקת!");
        } else {
            tvResult.setText("טעית...");
        }
מה כתבנו פה

getIntent() מחזיר את הבקשה שפתחה את המסך הזה.

getBooleanExtra("isCorrect", false) קורא ממנה את הפתק בשם "isCorrect". הערך השני, false, הוא ברירת מחדל: מה לקבל אם אין פתק בשם הזה.

הריצו ובדקו

ענו נכון ובדקו שכתוב "צדקת!". חזרו עם Back, ענו לא נכון ובדקו שכתוב "טעית...".

תמיד כתוב "טעית...", גם כשעניתם נכון?

אל תמחקו קוד ואל תמשיכו הלאה. זו תקלה שכדאי להבין לבד:

  1. שום דבר לא אדום והאפליקציה לא קורסת. כלומר הקוד תקין מבחינת Java, אבל המידע לא מגיע.
  2. שאלו את עצמכם: מתי getBooleanExtra מחזיר את ברירת המחדל?
  3. השוו אות אחרי אות בין שני הקבצים.
רמז

שם הפתק ב-putExtra (ב-MainActivity) חייב להיות זהה בדיוק לשם ב-getBooleanExtra (ב-ResultActivity), כולל אותיות גדולות וקטנות. "isCorrect" ו-"iscorrect" הם שני פתקים שונים. בדקו גם שלא שכחתם את שורת ה-putExtra באחד הכפתורים.

8

כפתור החזרה: finish

ב-ResultActivity.java, בסוף onCreate, אחרי ה-if:

        Button btnBack = findViewById(R.id.btnBack);
        btnBack.setOnClickListener(new View.OnClickListener() {
            @Override
            public void onClick(View v) {
                finish();
            }
        });
למה finish ולא Intent חדש

מסך השאלה לא נסגר כשעברתם למסך התוצאה. הוא מחכה מתחת, כמו קלף בערימה. finish() סוגר את המסך הנוכחי ומגלה את מה שמתחתיו. Intent חדש ל-MainActivity היה פותח עותק נוסף של מסך השאלה מעל הערימה, והערימה הייתה גדלה עם כל סיבוב.

בדיקת סיום של הפרויקט
  • מסך השאלה מציג שאלה שלכם ושני כפתורים.
  • תשובה נכונה פותחת מסך עם "צדקת!", תשובה שגויה פותחת מסך עם "טעית...".
  • "חזרה לשאלה" מחזיר למסך השאלה.
  • אחרי חזרה למסך השאלה, לחיצה אחת על Back של המכשיר יוצאת מהאפליקציה.
חלק 4

נקודת בדיקה

קראו למורה. תתבקשו להסביר בעל-פה את שלושת הדברים הבאים. הכינו את התשובות לפני כן, ונסו כל דבר באפליקציה שלכם.

א. קריסה מכוונת

פתחו את AndroidManifest.xml, סמנו את שלוש השורות של ResultActivity וגזרו אותן (Ctrl+X). הריצו ולחצו על אחד הכפתורים. האפליקציה תקרוס.

פתחו את חלון Logcat בתחתית Android Studio וחפשו את השורות האדומות. מה שם השגיאה? איזו שאלה Android שואל אתכם בהודעה? הדביקו את השורות חזרה (Ctrl+V) וודאו שהכול עובד שוב.

ב. מה יקרה אם

נחשו קודם, ורק אחר כך נסו:

  1. ב-ResultActivity משנים את ברירת המחדל מ-false ל-true, וגם משנים את שם הפתק ל-"result". מה יוצג כשעונים לא נכון, ולמה?
  2. מחליפים את finish() ב-Intent חדש ל-MainActivity. עונים על השאלה שלוש פעמים, ובכל פעם חוזרים בכפתור. כמה לחיצות על Back של המכשיר צריך עכשיו כדי לצאת מהאפליקציה, ולמה?

אל תשכחו להחזיר את הקוד התקין.

ג. במילים שלכם

מה ההבדל בין Activity לבין קובץ layout? ומה תפקידו של כל אחד משני הפרמטרים ב-new Intent(MainActivity.this, ResultActivity.class)?

חלק 5

הרחבות

כאן אין צעד-צעד. יש דרישה, הגדרת הצלחה ורמז. כל מה שצריך כבר מופיע במדריך הזה או במדריכים הקודמים.

הרחבה 1: צבע לפי התוצאה10 נק'

מסך התוצאה נראה אותו דבר כשצודקים וכשטועים. שנו את זה:

  • ב-colors.xml שני צבעים חדשים: result_correct (ירקרק) ו-result_wrong (אדמדם).
  • רקע מסך התוצאה משתנה לפי התשובה.
  • גם הטקסט שונה מ"צדקת!" ו"טעית...": נסחו הודעות משלכם שמתאימות לנושא החידון.

הצלחה: תשובה נכונה פותחת מסך ירקרק, תשובה שגויה פותחת מסך אדמדם.

רמז

הקופסה הראשית של המסך היא רכיב כמו כל רכיב אחר, ויש לה id. אפשר למצוא אותה עם findViewById(R.id.main) ולקרוא לפעולה setBackgroundColor. צבע מ-colors.xml מקבלים ב-Java עם getColor(R.color.result_correct).

הרחבה 2: הסבר לתשובה15 נק'

חידון טוב גם מלמד. הוסיפו למסך התוצאה משפט שמסביר מהי התשובה הנכונה ולמה.

  • ההסבר נכתב ב-MainActivity, ליד השאלה, ונשלח למסך התוצאה כפתק שני ב-Intent.
  • במסך התוצאה מופיע TextView חדש בשם tvExplanation, בין התוצאה לכפתור, והוא מציג את ההסבר שהתקבל.

הצלחה: אם משנים את טקסט ההסבר ב-MainActivity בלבד, מסך התוצאה מציג את הטקסט החדש.

רמז

Intent יכול לשאת כמה פתקים, כל אחד עם שם אחר. לפתק מסוג טקסט קוראים עם getStringExtra, והוא מקבל רק את שם הפתק, בלי ברירת מחדל.

הרחבה 3: שאלה שנייה15 נק'

חידון של שאלה אחת הוא לא חידון. הוסיפו מסך שלישי עם שאלה נוספת.

  • מסך חדש בשם SecondQuestionActivity, עם שאלה אחרת ושני כפתורים, שנראה כמו מסך השאלה הראשון.
  • במסך התוצאה נוסף כפתור "לשאלה הבאה" שפותח אותו.
  • גם השאלה השנייה שולחת את התשובה למסך התוצאה.
  • אחרי השאלה השנייה, הכפתור "לשאלה הבאה" לא מוצג.

הצלחה: אפשר לעבור שאלה, תוצאה, שאלה שנייה, תוצאה, ובמסך התוצאה האחרון אין כפתור "לשאלה הבאה".

רמז

מסך התוצאה צריך לדעת מאיזו שאלה הגיעו אליו. זה עוד פתק ב-Intent. כדי להעלים כפתור: setVisibility(View.GONE).

חלק 6

מסלול מתקדם

פתוח לכל מי שסיים את הפרויקט ואת נקודת הבדיקה. כאן אין צעדים ואין רמזים. יש יעד וקישור לתיעוד הרשמי, ואתם לומדים לבד. על כל משימה תצטרכו להסביר למורה מה עשיתם ולמה זה עובד.

מתקדם 1: מחזור החיים של מסך+10

מסך לא רק "קיים" או "לא קיים". הוא עובר בין מצבים, ובכל מעבר אנדרואיד קורא לפעולה מיוחדת.

  • בשני המסכים, דרסו את onStart, onResume, onPause, onStop ו-onDestroy, ובכל אחת (וגם ב-onCreate) הדפיסו שורה ל-Logcat עם Log.d, כולל שם המסך ושם הפעולה.
  • רשמו את סדר ההדפסות בשלושה מצבים: מעבר משאלה לתוצאה, חזרה עם finish(), ולחיצה על כפתור הבית של המכשיר.

למורה: במעבר משאלה לתוצאה, מה קורה קודם, onPause של השאלה או onCreate של התוצאה? והאם onDestroy של השאלה נקרא?

תיעוד: The activity lifecycle

מתקדם 2: Intent שיוצא מהאפליקציה+10

ה-Intent שכתבתם נקרא מפורש: הוא נוקב בשם המסך. יש גם Intent מרומז, שאומר רק מה רוצים לעשות, ואנדרואיד מחפש אפליקציה שיודעת לעשות את זה.

  • במסך התוצאה, כפתור "שתף" ששולח את התוצאה כטקסט דרך אפליקציה שהמשתמש בוחר (WhatsApp, מייל וכו'), בעזרת ACTION_SEND.
  • כפתור "למד עוד" שפותח בדפדפן דף אינטרנט שקשור לשאלה, בעזרת ACTION_VIEW.

למורה: מה ההבדל בין Intent מפורש למרומז, ומי מחליט איזו אפליקציה תיפתח?

מתקדם 3: חמש שאלות, מסך שאלה אחד+10

מסך נפרד לכל שאלה (כמו בהרחבה 3) לא מחזיק מעמד בחידון של עשרים שאלות. בנו את החידון נכון:

  • השאלות והתשובות שמורות במערכים.
  • יש מסך שאלה אחד בלבד, שמציג את השאלה לפי מספר שהוא מקבל ב-Intent.
  • הניקוד המצטבר עובר ממסך למסך.
  • בסוף מוצג מסך סיכום: כמה צדקתם מתוך חמש.
