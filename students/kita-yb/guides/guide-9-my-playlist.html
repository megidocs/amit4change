אימות הבנה עם המורהדוגמה

בכל תיבה יש משימה: להסביר קוד, או להסביר איך הייתם מתאימים את הפתרון לדרישה חדשה. קודם עונים לעצמכם, ורק אז קוראים למורה ומסבירים בעל-פה, בלי להסתכל במדריך.

לכל נקודת אימות יש מספר, למשל נקודת אימות 3. המורה רושם אצלו לפי המספר, אז כשאתם קוראים למורה, אמרו את מספר הנקודה.

המדריך נפתח בהדרגה

אחרי כל אחת מנקודות האימות 1 עד 7, ההמשך של המדריך נעול. אחרי השיחה המורה ייתן לכם קוד בן 5 תווים, ואתם מקלידים אותו בתיבה שמתחת לנקודה. אחרי נקודה 7 נפתח כל ההמשך. גם בנקודות האימות של ההרחבות ושל המסלול המתקדם מקבלים קוד מהמורה, אבל שם הוא לא נועל כלום: הוא רק רושם שעברתם.

כל קוד נכון נרשם אוטומטית בטבלה של המורה, עם השם שלכם והשעה.

  • בפעם הראשונה תתבקשו להקליד את שמכם: שם פרטי ושם משפחה בלבד, בלי שם שני. למשל: ישראל ישראלי. המורה מקליד בטלפון שלו בדיוק את אותו שם.
  • רשמו כל קוד במחברת. אם תעבדו בשיעור הבא על מחשב אחר, תקלידו את הקודים שוב כדי לפתוח את מה שכבר עברתם.
  • בסוף שיעור במחשב של הכיתה לחצו "סיום עבודה במחשב הזה" בתחתית הדף, כדי שהתלמיד הבא לא ימשיך מהמקום שלכם.

חזרה: שני מסכים ושיר אחד

בחזרה בונים את השלד של האפליקציה: מסך ראשי, מסך של שיר, ומעבר ביניהם שמעביר את שם השיר ואת שם האמן. את מסך השיר נשתמש בו שוב בסוף הפרויקט.

  1. צרו פרויקט חדש בשם MyPlaylist. תבנית Empty Views Activity, שפה Java, ‏Minimum SDK ‏API 26, ‏Build configuration language ‏Groovy DSL.
  2. חובה, לפני שמוסיפים רכיב כלשהו: פתחו את activity_main.xml במצב Code, מחקו את כל התוכן שלו והדביקו במקומו את שלד ה-LinearLayout שמופיע מתחת לרשימה.
  3. בתוך השלד: TextView בשם (id) tvTitle עם הטקסט "הפלייליסט שלי" (28sp, ממורכז), ומתחתיו כפתור בשם (id) btnOpen עם הטקסט "שיר לדוגמה".
  4. צרו מסך (Activity) חדש: לחיצה ימנית על התיקייה app ← New ← Activity ← Empty Views Activity. השם: SongActivity, השפה: Java.
  5. ב-activity_song.xml שימו את אותו שלד, ובתוכו: TextView בשם (id) tvSongTitle (28sp), TextView בשם (id) tvSongArtist (20sp), וכפתור בשם (id) btnBack עם הטקסט "חזרה לרשימה". לשני ה-TextView לא כותבים טקסט ב-XML. הטקסט שלהם יגיע מהקוד, מהנתונים שהמסך הראשי שולח.
  6. לחיצה על btnOpen פותחת את מסך השיר, ושולחת אליו שני נתונים עם putExtra: שם השיר "Bohemian Rhapsody" בשם "title", ושם האמן "Queen" בשם "artist".
  7. מסך השיר קורא את שני הנתונים ומציג אותם. לחיצה על btnBack סוגרת את המסך עם finish().
  8. הריצו ובדקו.

רמז: שליחת הנתונים מהמסך הראשי

ב-MainActivity.java, בתוך onCreate:

Button btnOpen = findViewById(R.id.btnOpen);
btnOpen.setOnClickListener(new View.OnClickListener() {
    @Override
    public void onClick(View v) {
        Intent intent = new Intent(MainActivity.this, SongActivity.class);
        intent.putExtra("title", "Bohemian Rhapsody");
        intent.putExtra("artist", "Queen");
        startActivity(intent);
    }
});
רמז: קריאת הנתונים במסך השיר

ב-SongActivity.java, בתוך onCreate, אחרי הקוד שכבר נמצא שם:

TextView tvSongTitle = findViewById(R.id.tvSongTitle);
TextView tvSongArtist = findViewById(R.id.tvSongArtist);
Button btnBack = findViewById(R.id.btnBack);

tvSongTitle.setText(getIntent().getStringExtra("title"));
tvSongArtist.setText(getIntent().getStringExtra("artist"));

btnBack.setOnClickListener(new View.OnClickListener() {
    @Override
    public void onClick(View v) {
        finish();
    }
});
