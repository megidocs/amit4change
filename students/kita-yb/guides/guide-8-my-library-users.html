בכל תיבה יש משימה: להסביר קוד, או להסביר איך הייתם מתאימים את הפתרון לדרישה חדשה. קודם עונים לעצמכם, ורק אז קוראים למורה ומסבירים בעל-פה, בלי להסתכל במדריך.

לכל נקודת אימות יש מספר, למשל נקודת אימות 3. המורה רושם אצלו לפי המספר, אז כשאתם קוראים למורה, אמרו את מספר הנקודה.

המדריך נפתח בהדרגה

אחרי כל אחת מנקודות האימות 1 עד 7, ההמשך של המדריך נעול. אחרי השיחה המורה ייתן לכם קוד בן 5 תווים, ואתם מקלידים אותו בתיבה שמתחת לנקודה. אחרי נקודה 7 נפתח כל ההמשך. גם בנקודות האימות של ההרחבות ושל המסלול המתקדם מקבלים קוד מהמורה, אבל שם הוא לא נועל כלום: הוא רק רושם שעברתם.

כל קוד נכון נרשם אוטומטית בטבלה של המורה, עם השם שלכם והשעה.

  • בפעם הראשונה תתבקשו להקליד את שמכם: שם פרטי ושם משפחה בלבד, בלי שם שני. למשל: ישראל ישראלי. המורה מקליד בטלפון שלו בדיוק את אותו שם.
  • רשמו כל קוד במחברת. אם תעבדו בשיעור הבא על מחשב אחר, תקלידו את הקודים שוב כדי לפתוח את מה שכבר עברתם.
  • בסוף שיעור במחשב של הכיתה לחצו "סיום עבודה במחשב הזה" בתחתית הדף, כדי שהתלמיד הבא לא ימשיך מהמקום שלכם.

ניקוד על ההרחבה ועל המסלול המתקדם נרשם רק אחרי שעברתם את שבע עצירות אימות ההבנה של החזרה והפרויקט.

ממשיכים מאותו פרויקט

עובדים על הפרויקט MyLibrary ממדריך 7, ועל אותו repository. במחשב של הכיתה: עשו Clone ל-repository שלכם בתחילת השיעור, כמו בשגרה של מדריך GitHub. הקובץ google-services.json נמצא ב-repository, ולכן החיבור ל-Firebase עובד גם אחרי Clone. אחרי כל צעד שעובד: Commit ו-Push.

חלק 1

חזרה: מתודה לטעינה

איפה עובדים: Android Studio

במדריך 7 קוד הטעינה כתוב בתוך onClick של btnLoad. היום נצטרך לטעון את הספר גם בפתיחת המסך, ולכן מעבירים את הקוד למתודה, כמו readNumber במחשבון הממוצע.

  1. פתחו את MainActivity.java.
  2. מחוץ ל-onCreate, אחרי הסוגר המסולסל שלה, צרו מתודה ריקה: void loadBook() { }
  3. העבירו לתוכה את כל הקוד שכרגע בתוך onClick של btnLoad: גזירה (Ctrl+X) והדבקה (Ctrl+V).
  4. ב-onClick של btnLoad נשארת שורה אחת: loadBook();
  5. בסוף onCreate, לפני הסוגר שלה, הוסיפו גם שם: loadBook();
  6. הריצו ובדקו.
נתקעתי: איך נראית המתודה 
    void loadBook() {
        tvStatus.setText("טוען...");

        db.collection("books").document("current").get()
                .addOnSuccessListener(new OnSuccessListener<DocumentSnapshot>() {
                    @Override
                    public void onSuccess(DocumentSnapshot doc) {
                        if (!doc.exists()) {
                            tvStatus.setText("עוד אין ספר שמור");
                            return;
                        }
                        etBook.setText(doc.getString("title"));
                        etAuthor.setText(doc.getString("author"));
                        Long pages = doc.getLong("pages");
                        if (pages != null) {
                            etPages.setText(String.valueOf(pages));
                        } else {
                            etPages.setText("");
                        }
                        tvStatus.setText("נטען מהענן");
                    }
                })
                .addOnFailureListener(new OnFailureListener() {
                    @Override
                    public void onFailure(@NonNull Exception e) {
                        tvStatus.setText("הטעינה נכשלה: " + e.getMessage());
                    }
                });
    }
